# Deprecated Adapter Documents 

This directory contains some HyperFleet adapters that are now deprecated:

- DNS: as it was GCP specific and the GCP team will take over if needed
- validation: as it was GCP specific and the GCP team will take over if needed
- pullSecret: as the need for it has yet to be confirmed/prioritized
- hypershift: deprecated in favor of using maestro transport for manifestworks
- maestro-cli: deprecated in favor of using maestro API
